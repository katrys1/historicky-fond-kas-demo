# historicky-fond-kas-demo
Interaktivní digitální kurátorský katalog historického fondu KAŠ – projekt ve vývoji


Veřejná ukázka vycházející z KAŠ 7.1, projekt ve vývoji.

## Obsah
- Mattioli, Herbář aneb bylinář (1596), ZB30
- Hohberg, Georgica curiosa (1682), B1487, první díl
- Linné / Willdenow, Species plantarum (1799), SZE67/2/2

## Funkce
Vyhledávání a filtr století, pracovní katalogizace MARC 21, sedmikrokový badatelský průvodce, zdrojové soubory a OCR, AI zadání, kurátorské výstupy a lokální export zálohy.

Upozornění: Nejde o serverovou aplikaci. Pracovní data a vložené soubory zůstávají lokálně v prohlížeči konkrétního návštěvníka. Import celého katalogu a přidávání dalších knih jsou v DEMO vypnuty. AI funkce připravují kopírovatelná zadání, nevolají externí model automaticky.
